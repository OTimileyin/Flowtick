# Flowtick — Approved Resources

Use external resources only when they solve a specific need.

## UI and design
- skiper-ui.com — implementation-ready components where useful
- fancycomponents.dev — selective premium interactions
- agentation.com — precise visual review and targeted edits
- getstage.co — UX/design research
- metalforge.xyz — loading-state references where async behavior exists
- limora.ai — brand-matched assets when real custom assets are needed

## AI app resources
- libraries.dev/orbs — Phase 2 only if Flowtick gets real AI features

## Charts
- benji.org/liveline — only if real live charting becomes part of the product

## Additional implementation resources
- Radix Primitives — accessible behavior for complex controls
- Motion — restrained UI transitions
- GSAP ScrollTrigger — only for a deliberate scroll-driven product demonstration
- Vercel web-design guidelines — final interface polish
- Anthropic frontend design guidance — anti-template visual direction

## Usage rules
- Do not install or use every resource.
- Use only the smallest set needed.
- External components must be adapted to Flowtick.
- Accessibility and responsiveness must be preserved.
- Do not let external resources override `PRD.md`.
