# Flowtick

Flowtick is a lightweight personal todo application built with React and Vite.

## Core features
- Add tasks
- Edit tasks
- Complete/uncomplete tasks
- Delete tasks
- Filter tasks
- Persist tasks in localStorage
- Responsive and accessible interface

## Stack
- React
- Vite
- JavaScript
- CSS

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
